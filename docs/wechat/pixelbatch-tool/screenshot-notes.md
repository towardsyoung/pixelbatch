## 发布前检查

* 建议保留 16:9 的横向截图；公众号正文中可直接上传原图，或按平台要求压缩后上传。
* 第 6 张图可能显示本地配置的接口地址。发布前请确认接口地址、账号名、工作目录和其他环境信息可以公开；如果不能公开，先裁剪或打码。
* 截图不应出现真实 API Key、访问令牌或账单信息。PixelBatch 界面不会主动展示完整密钥，但发布前仍建议逐张复核。
* 如果需要配封面，可以从第 1 张或第 5 张截取局部，叠加标题“电商图片批处理工作流”，避免把整张界面缩得过小。
* 如果公众号编辑器不支持相对路径预览，请先把 `screenshots/` 下的图片逐张上传，再将图片替换为公众号素材库中的图片。
