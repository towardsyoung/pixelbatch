# PixelBatch 公众号文章内容包

这个目录是 PixelBatch 的公众号分享素材，包含：

* `pixelbatch-wechat-article.md`：精简后的公众号正文，已包含 GitHub 地址和本地截图引用。
* `screenshot-notes.md`：截图用途、建议图注和发布前隐私检查清单。
* `screenshots/`：文章正文使用的 6 张真实应用界面截图。

文章使用开发者第一人称，从电商图片处理中的重复操作切入，说明批量导入、提示词复用、任务追踪、结果检查和批量导出。

项目公开地址：<https://github.com/towardsyoung/pixelbatch>

发布到微信公众号时，需要将 Markdown 中的相对图片路径逐张上传到公众号素材库，再把图片替换为对应素材。截图发布前请重点检查模型设置页是否包含不能公开的接口地址、账号信息或其他本地环境信息。
